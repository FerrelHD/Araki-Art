# araki.

> Haute-Couture Lookbook & Editorial Archive

An interactive editorial archive documenting the intersection of **Hirohiko Araki** (*JoJo's Bizarre Adventure*) with international haute-couture fashion, classical Renaissance sculpture, and glam rock culture. Inspired by Swiss 12-column blueprint grid design and the brutalist-editorial motion of [mijobello.com](https://mijobello.com/).

---

### Features

* **12-Column Blueprint Grid**: Swiss precision overlay and modular cell structure.
* **Cinematic Slat Preloader**: Opening curtain lift with counter sequence.
* **Live Fashion Capitals Marquee**: Real-time clocks for Paris, Milan, Roma, Tokyo, and Naples.
* **Chromatic Shift Toggle**: Instant switch between *Runway Paper* and *Menacing* JoJo palettes.
* **Selected Capsules Slider**: Hover-triggered project preview with editorial clip-path curtain wipes.
* **Anatomy Accordion**: Expanding rows with kinetic media reveal.
* **Smooth Inertia Scroll**: Lenis integrated with GSAP ticker for 60 FPS synchronization.

---

### Tech Stack

* **Framework**: Vue 3 (Composition API) + TypeScript
* **Bundler**: Vite
* **Styling**: Tailwind CSS v4
* **Motion & Animation**: GSAP 3 (ScrollTrigger)
* **Smooth Scrolling**: Lenis
